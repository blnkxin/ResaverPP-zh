# ReSaver++ 汉化术语表（统一用词，务必遵守）

本项目是《上古卷轴5：天际》存档清理工具 ReSaver 的 C++ 复刻版（ImGui 界面）。
界面语言目标：**简体中文**。技术专有名词按下面的表格处理。

长度：按钮/菜单/列标题尽量 2–6 个字；提示句可完整。
